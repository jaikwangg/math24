# 🧮 Math Game

ยินดีต้อนรับสู่ **Math Game** เกมสนุกๆ ที่ช่วยฝึกทักษะคณิตศาสตร์ของคุณผ่านการเล่นและการท้าทายที่น่าตื่นเต้น

## 📌 คุณสมบัติที่สำคัญ

- **เกมคณิตศาสตร์สนุกสนาน**: ฝึกฝนทักษะคณิตศาสตร์พื้นฐานผ่านเกมที่ออกแบบมาอย่างน่าสนใจ
- **รองรับผู้เล่นทุกวัย**: ออกแบบมาสำหรับทุกวัย ทั้งเด็กและผู้ใหญ่
- **คะแนนและสถิติ**: บันทึกคะแนนและแสดงสถิติการเล่นเพื่อวัดพัฒนาการ
